# 验证与已知边界

## 已确认的最近修复

2026-10-12两份崩溃记录发生在USB保持运行的OBS退出流程。原先模块在卸载时才停止输出，而OBS已释放音频设备；`audio_output_disconnect` 随后访问失效的互斥量，触发0xC0000005。

修复位于 `native-obs-usb/src/applelive_output.cpp`：在前端SCRIPTING_SHUTDOWN/EXIT事件提前停止，注册输出类型的 `free_type_data` 提供无前端宿主的提前关闭路径；关闭开始后拒绝新连接控制请求，等待线程释放输出；卸载时重复清理保持幂等。

当时验证结果：旧DLL在真实libobs中复现0xC0000005；修复DLL通过25次启停、3轮H264/AAC接收、2项完整OBS带USB退出场景。GUI测试中普通退出约3.083秒、并发请求退出约2.101秒，均返回0。它们是已记录的测试结果，不是所有机器/时长的稳定性保证。

## 电脑回归命令

先按编译文档生成当前组件，再从项目根目录执行：

```powershell
python desktop_sender/protocol_test.py
python desktop_sender/dock_test.py
python desktop_sender/obs_websocket_test.py
node --test desktop_sender/dock_ui_test.js
python native-obs-usb/tests/relay_test.py
python native-obs-usb/tests/obs_host.py $ObsRoot '.build/usb-regression' --shutdown-active --stop-cycles 25
python scripts/verify-native-shutdown.py $ObsRoot '.build/native-obs-output/Release/applelive-native-output.dll'
python scripts/verify-portable-startup.py $ObsRoot
```

GUI测试应使用完整便携运行目录，并通过随机本机端口与用户实例隔离；启动验证脚本当前断言版本0.4.5，后续升级版本时要同步更新断言。这些脚本会生成较大的OBS副本，测试完及时清理自己的 `.build` 输出。

手机构建中的颜色、解码、鱼眼、音频、UVC内存和生命周期测试见 `build-ios-injector.yml`。自动化测试不可替代目标App实机验证。

## 发布前实机验收

- 用干净Windows环境解压客户包，从根目录启动；脚本、WebSocket、停靠面板无需手工配置。
- USB准备就绪，手机连接后有连续声音与画面；OBS“开始直播”保持关闭时仍能传输。
- 断线、重插、手机App重启、电脑重复启停、带USB退出都可恢复；分别检查音画和状态文案。
- LAN模式分别验证RTMP与RTSP；换电脑后使用新电脑IP，两种协议都测试。
- 核对方向、比例、亮度/色彩、内录音量及鱼眼关闭后的原始效果。
- 按实际目标时长持续使用并记录App版本、机型、iOS、越狱/注入方式、电脑OBS与驱动版本。

## 兼容性边界

- 已有主要实测基线是iPhone11 / iOS15.6，Dopamine环境，抖音；其他设备/App必须逐项验证。
- arm64最低部署目标14.0、arm64e最低15.0只是二进制目标，不等于所有这些及更高系统都有可用越狱/注入方式，也不代表已测全版本。
- 原生OBS API声明固定于30.2.3。第三方定制OBS使用的宿主版本是30.2.3派生；不能假定任意OBS新版本兼容。
- iOS13/rootful文件保留为历史兼容源码，并不表示当前单文件dylib可以安装在iOS13。当前交接重点为iOS15及以上。
- UVC/Lightning外接摄像头属于实验路线，权限、芯片、转接器、采集格式可能不同，尚无“任意品牌可用”的验证。电脑USB直连不依赖它。
- 本次整理没有重新执行云端全量构建或新的手机长时间实测；参考成品和测试记录来自已完成构建。

## 常见定位入口

- `config/obs-studio/logs`、`crashes`：OBS日志/崩溃记录。
- `config/applelive-startup.log`：启动配置日志。
- `http://127.0.0.1:18765/api/status`：本机面板状态；返回内容可能带控制令牌，分享日志时不要整体公开。
- 当前模块日志必须含 `lifecycle fix 2026-10-12` 才能确认退出修复已实际加载。
