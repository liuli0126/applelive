# 架构与代码入口

## USB直连

`OBS合成画面与混音 → applelive-native-output.dll → AppleLiveUsbRelay.exe → Apple Mobile Device服务/usbmux → 手机ALUSBReceiver → 视频/音频解码 → 目标App画面与内录`

电脑点“准备USB直连”建立独立OBS输出；不要求OBS点击“开始直播”，也不需要Wi-Fi、RTMP/RTSP地址或SSH。手机选择USB直连并连接。客户仍须安装可用的苹果设备驱动、解锁手机并信任电脑。

- `native-obs-usb/src/applelive_output.cpp`：注册独立输出、H264/AAC编码、有限队列、控制端口、退出生命周期。
- `native-obs-usb/src/applelive_usb_relay.cpp`：选择USB设备、usbmux通道、握手与转发。
- `native-obs-usb/include/applelive_protocol.h`：传输协议。
- `ios-injector/ALUSBReceiver.m`：手机回环监听与接入。
- `ios-tweak/ALStreamClient.m`、`ALVideoDecoder.m`：流状态、VideoToolbox/AAC解码与重连。
- `ios-tweak/Tweak.xm`、`ALFrameStore.m`、`ALAudioRing.m`：画面和音频替换所需的共享处理。
- `ios-injector/ALSampleAudio.m`、`ALAudioUnitBridge.m`：内录音频接入。

握手为 `ALUSB1\r\n`。包头是大端32位负载长度，视频 `fram` 内字段按小端保存；H264为Annex-B访问单元，AAC通过 `aacd` 配置、`aaca` 帧传输。协议细节及关键帧门控见 `native-obs-usb/README.md`。修改任一端协议时，必须同步验证另一个端。

## 局域网

`OBS推RTMP → 电脑内置MediaMTX → 手机拉RTMP或RTSP → ALMediaPlayer/FFmpeg → 目标App`

电脑获取推流码时启动本地服务并配置OBS；局域网开播/下播与OBS推流关联。手机支持两种地址：

```text
rtmp://电脑局域网IP:1935/live/applelive
rtsp://电脑局域网IP:8554/live/applelive
```

- `desktop_sender/stream_server.py`、`obs-plugin/server/mediamtx.yml`：内置媒体服务。
- `desktop_sender/obs_websocket.py`：OBS配置与控制。
- `ios-injector/ALMediaPlayer.m`：手机RTMP/RTSP和文件媒体读取。

## 启动与停靠面板

`福煋OBS.exe → 初始化便携配置 → 启动AppleLiveDock → 启动真实AppleLiveOBS.exe → 内置浏览器停靠窗口`

- `native-obs-usb/src/applelive_launcher.cpp`：启动器、重复启动处理、先启动面板服务。
- `obs-plugin/install_or_update.ps1`：脚本/WebSocket/停靠窗口配置迁移与场景保留。
- `obs-plugin/AppleLive.lua`：加载入口；启动器已预启动面板服务时避免重复启动。
- `desktop_sender/dock_server.py`：状态、操作接口、组件进程管理。
- `obs-plugin/dock/`：面板HTML/CSS/JavaScript、图标和默认布局。
- `scripts/build-portable-obs.ps1`：把组件及OBS组织成客户可解压运行的目录。

当前WebSocket密码在客户首次启动时生成，不能把开发机的配置或密码直接分发。

## 默认端口

| 端口 | 角色 |
|---|---|
| 18765 | 电脑本机停靠面板HTTP服务 |
| 4455 | OBS WebSocket |
| 28766 | 原生USB输出控制 |
| 28765 | 原生输出连接USB中继 |
| 27015 | 苹果设备usbmux服务 |
| 8766 | 手机本机USB接收监听 |
| 1935 / 8554 | LAN RTMP / RTSP |

`APPLELIVE_TEST_DOCK_PORT`、`APPLELIVE_TEST_WEBSOCKET_PORT`、`APPLELIVE_TEST_CONTROL_PORT`、`APPLELIVE_TEST_RELAY_PORT` 用于隔离自动验证。

## 手机界面与可选功能

- 面板：`ios-injector/ALMediaPanel.m`、`ALCyberTheme.m`、`ALSourceSettings.m`。
- 图标/名称：`ios-tweak/ALBrand.h`、`ALBrandImage.h`；电脑原图在 `assets/brand/`。
- 颜色与元数据：`ios-tweak/ALColorPipeline.m`。
- 鱼眼强度：`ios-tweak/ALVideoEffects.m`、`ALControls.m`。
- 外接UVC：`ALExternalCamera`、`ALUVC*` 及 `ios-uvc-service/`，当前仍需设备权限、转接器和具体硬件验证。

用户启用内录时，由媒体源音频替换麦克风输入；缺少媒体音频或缓冲欠载时填静音。排查无声需分别检查OBS混音、传输包、解码音频、目标App音频接入，不能仅凭有画面判断音频通路正常。
