- 电脑端：福煋OBS **0.4.5，含 2026-10-12 USB退出崩溃修复**。停靠面板仍显示0.4.5；原生模块日志带 `lifecycle fix 2026-10-12`。

- 手机云端构建编号38126000459，核心手机源代码与该构建的源快照一致（忽略换行差异）。本地 `scripts/build-uvc-service.sh` 有额外的可选服务打包调整，已一并交接。
- 客户运行包：另行交付的 `福煋OBS.zip`。源码包内保留编译依赖和参考产物，未重复装入完整OBS本体。

## 目录

| 目录 | 用途 |
|---|---|
| `native-obs-usb/` | OBS原生H264/AAC输出、USB中继、Windows启动器源码 |
| `desktop_sender/` | 电脑停靠面板HTTP服务、OBS WebSocket客户端、网络服务器控制、旧安装兼容发送器 |
| `obs-plugin/` | Lua加载器、网页停靠面板、安装脚本、配置模板及当前参考可执行文件 |
| `ios-injector/` | 独立dylib界面、媒体输入、内录音频桥接、USB接收和实验性外接相机 |
| `ios-tweak/` | 与独立dylib共享的视频/音频解码、画面替换、滤镜和控制代码；旧越狱包构建入口 |
| `ios-uvc-service/` | 可选UVC服务源码，不是普通USB电脑直连必装组件 |
| `scripts/` | 编译、验证和打包脚本 |
| `.github/workflows/` | 云端iOS/Windows构建任务 |
| `assets/brand/` | 用户提供的品牌图标及转换资源 |
| `docs/` | 历次功能说明与本次交接文档 |
