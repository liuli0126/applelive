# 手机鱼眼效果开关

在 AppleLive 手机悬浮窗的“02 / 画面控制”中增加“鱼眼效果”开关。默认关闭，打开后立即应用，关闭恢复原画面；设置按当前 App 保存。面板增加滚动支持，避免新增设置挤出小屏或横屏范围。

效果接入共用画面处理路径，适用于 USB、RTMP/RTSP 及本地画面，也用于插件预览。镜像、旋转、完整/铺满和原有色彩处理继续生效。切换效果不重新连接、不切换信号源，也不清空音频。

采用固定投影强度的等距鱼眼模拟，中心和对角角点保持对应，周围直线呈弯曲。它只改变现有画面的几何形状。Core Image warp kernel 只编译一次并复用；使用同一像素尺度处理两个轴，避免竖屏变成椭圆镜头。关闭直接返回原图，不经过效果处理。
