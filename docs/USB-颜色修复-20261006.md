# USB 画面颜色修复

用户已确认 iPhone 11 / iOS 15.6 / 抖音的 USB 画面和声音正常，本次处理手机画面相对 OBS 泛白、颜色不同的反馈。

## 已复现的问题

电脑运行配置为 NV12、Rec.709、Partial。旧手机代码在原始相机缓冲区内渲染替换画面时，强制把颜色附件改成 BT.709；原始 CMSampleBuffer 的格式说明没有跟着变。遇到采用 601 矩阵或者 sRGB 的相机输出时，像素和 App 读取的格式说明会不一致。

macOS 自动测试 37406249875 已复现：有限范围和全范围的 709 测试均通过，但全范围 601 的目标相机格式一致性断言失败。因此本次没有加入整体提亮、压暗或者强制扩大色彩范围的补偿。

## 修改

- 渲染时保留目标相机的颜色附件，由其实际颜色空间、矩阵和像素格式决定转换。
- 输入帧根据实际颜色附件创建颜色空间，避免把所有非 sRGB 输入都强制解释为 709。
- 插件自己创建的 BGRA 预览使用 sRGB，在创建 sample 的格式说明之前设置颜色附件。
- USB 传输协议、声音、电脑编码及现有 OBS 设置保持兼容，本次只需更新手机 dylib。

## 验证范围

测试包含有限范围 709、全范围 709、全范围 601 的黑白灰及彩色块，并将输出与独立 YUV 矩阵计算值比较；同时检查原始相机格式说明与渲染后的像素缓冲区保持一致，以及 BGRA 黑位和透明度。24 组 YUV 色块的每个分量与参考值相差不超过 1，黑、白、灰亮度均与参考值一致。
