# 手机鱼眼强度调节

用户确认问题是抖音预览中的鱼眼变形不够明显。本次在“鱼眼效果”开关下面增加强度滑块，开启效果后显示，关闭时收起。

- 0%：直接使用原画面。
- 75%：与上一版固定鱼眼效果对应，升级采用此默认值。
- 100%：更强的变形。可先试 90%，再按画面调整。

拖动实时更新画面，松手或短暂停留后自动保存，避免拖动期间反复写入设置。关闭开关保留强度，再打开沿用之前的数值。VoiceOver 调整也会保存。切换效果和强度不重新连接，不清空音频。

共享画面处理路径适用于 USB、RTMP/RTSP 和本地来源。投影半角按强度从 0 到 80 度变化，75% 对应之前的 60 度；最高值仍低于正切函数的奇点。内核只编译一次，拖动仅更新参数，保留上版的边界处理和色彩修复。越狱控制通知增加强度值及存在标志，兼容没有发送强度的旧版本，并区分“未设置”与明确设置为零。

验证涵盖旧设置默认、非法/越界数值、即时通知、保存和零值保留；实际渲染检查弱/原有/最高强度的变化、横竖屏、中心、边界透明度、颜色常量，以及关闭后恢复原图。

源码 `af16228` 的完整手机构建 [37410354601](https://github.com/liuli0126/applelive/actions/runs/37410354601) 通过，包括鱼眼、颜色、USB H.264/AAC 解码与重连、音频替换、RTMP/RTSP 和 arm64/arm64e 编译验证。rootless 与 iOS 13 rootful 构建也通过（37410354656 / 37410354640）。测试图中，256×192 画面的测量位移从 75% 时的 35.098 增至 100% 时的 80.662；这是该测试图的几何测量，不代表所有画面的主观强度倍数。已检查 GPU 三栏对比图，最高强度的弯曲更加明显，边界没有溢出。
